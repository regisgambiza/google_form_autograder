**Correct Answer:** 4 ½  

**Explanation / Steps:**

## Question 35: Explain why converting mixed numbers to improper fractions before adding can be useful. (SHORT_ANSWER)
**Correct Answer:**  
Converting mixed numbers to improper fractions before adding is useful because it puts every number into the same format. This lets you use one common‑denominator method on the numerators, add them directly, and then change the final result back to a mixed number only at the end. It keeps the process systematic and reduces mistakes.

**Explanation / Steps:**
1. **Turn each mixed number into an improper fraction.**  
   *Example:* 3 ½ → (3×2 + 1)/2 = 7/2.  
2. **Find one common denominator for all fractions.**  
   *Example:* If you have 7/2 and 5/3, the common denominator is 6.  
3. **Rewrite each fraction with that common denominator.**  
   *Example:* 7/2 = 21/6, 5/3 = 10/6.  
4. **Add the numerators together.**  
   *Example:* 21/6 + 10/6 = 31/6.  
5. **Simplify if possible, then convert back to a mixed number.**  
   *Example:* 31/6 = 5 1/6.

---

## Feedback  
Great job on simplifying the addition! Remember that converting to improper fractions first keeps everything in the same shape, making the calculation smoother.

2. **Skipping the common‑denominator step** – each fraction must share the same denominator before adding.
