## Question 3: 4c means 4 × c. (MULTIPLE_CHOICE)
**Correct Answer:** True  

**Explanation / Steps:**  
1. In algebra, when a number is written right next to a letter, it means the number multiplies the letter.  
2. The expression “4c” has no sign between 4 and c.  
3. Therefore the operation is 4 × c.  
4. So “4c” is true: it means 4 times c.

## Feedback  
Great job on most of the questions! You’re recognizing that letters next to numbers represent multiplication. Keep it up!

## Common Mistakes

- Thinking “4c” could be a single number or a string instead of a product.  
- Missing the rule that letters represent variables that must be multiplied by the number.

## Keep Practicing  
Try writing a few more expressions like 7x, 5y, and 9z. Remember: number + letter = number × letter. Good luck!

## Question 4: a + b = ab. (MULTIPLE_CHOICE)
**Correct Answer:** False  

**Explanation / Steps:**
1. The statement says “a + b = ab” is true for all numbers a and b.  
2. Check a few examples.  
   * 1 + 1 = 2, but 1 × 1 = 1 → not equal.  
   * 2 + 2 = 4, and 2 × 2 = 4 → equal, but this is only one special case.  
3. Because the equality is not true for every possible a and b, the statement is **False**.  

## Feedback  
Great job on many of your answers! Keep paying attention to whether a rule works for *all* numbers, not just a few examples.

## Common Mistakes  
1. Thinking the rule is true just because it works for one pair of numbers.  
2. Mixing up addition and multiplication.  
3. Forgetting that 0 + 0 = 0 × 0 is also a special case.

## Keep Practicing  
Try testing random pairs of numbers on your own to see if the equation holds. Remember, a rule is only true if it works for every possible pair. Good luck!

## Question 20: Daniel spends twice as long as Peter, who spends (2m + 3) minutes. Form an expression for Daniel’s time. (SHORT_ANSWER)
**Correct Answer:** (4m + 6)

**Explanation / Steps:**
1. Peter’s time is \(2m + 3\) minutes.  
2. Daniel spends twice as long, so we multiply Peter’s time by 2:  
   \(2 \times (2m + 3)\).  
3. Distribute the 2:  
   - \(2 \times 2m = 4m\)

4. Add the two parts together: \(4m + 6\).  
5. Therefore Daniel’s time is \((4m + 6)\) minutes.

2. **Wrong distribution** – some students wrote `2(2m+3)` but didn’t multiply to get `4m+6`.  
3. **Typing errors** – writing `2x` or `5m` instead of the correct formula.

## Keep Practicing  
Try writing the full equation first (Peter’s time × 2) before simplifying. Practice with other numbers to see the pattern. Good work!
