## Question 20: The simplified form of 4b + 3 is 7b. (MULTIPLE_CHOICE)
**Correct Answer:** Wrong  

**Explanation / Steps:**  
1. The expression is **4b + 3**.  
2. **4b** contains the variable *b*; **3** is a number only.  
3. Because one term has a variable and the other does not, they are **not like terms**.  
4. Like terms can be added or subtracted, but unlike terms cannot.  
5. Therefore the expression cannot be simplified to a single term such as **7b**.  
6. The simplest form is still **4b + 3**.  

## Feedback  
Good job trying to solve the problem! Remember that you can only combine terms that are alike.  

## Common Mistakes  
1. Adding a number to a variable term (e.g., treating 4b + 3 as 7b).  
2. Thinking that the numbers in the terms can be added when the variables differ.  
3. Forgetting that a constant (3) cannot be combined with a variable term (4b).  

## Keep Practicing

## Question 22: Simplifying 3a + 4b gives 7ab. (MULTIPLE_CHOICE)
**Correct Answer:** Wrong  

**Explanation / Steps:**  
1. The expression is 3a + 4b.  
2. In algebra, only terms that have the same variable (like 3a and 5a) can be added together.  
3. Here 3a has the variable “a” and 4b has the variable “b”.  
4. Because the variables are different, 3a and 4b are **unlike terms**.  
5. Unlike terms cannot be combined, so the expression stays as **3a + 4b**.  
6. Therefore the statement “Simplifying 3a + 4b gives 7ab” is **incorrect**.  

## Feedback  
Great job trying to simplify! Keep looking closely at the variables in each term; that’s the key to adding correctly.  

## Common Mistakes  
1. **Mixing the coefficients and variables** – thinking 3a + 4b could become 7ab by adding 3 and 4.  
2. **Assuming a equals b** – treating different letters as the same variable.  
3. **Adding instead of multiplying** – converting 3a + 4b into 3a × 4b (which would be 12ab).  

## Keep Practicing  
Practice finding like terms in more expressions, and write them side‑by‑side. Remember: only terms with the exact same variable (and exponent) can be added together. Good luck!

2. **Missing the 2q term** – forgetting to include the 2q when writing the final answer.  

## Keep Practicing  
Try simplifying other expressions like 3x + 5x + 4y or 2a + a + 6b. Remember: only combine terms that share the same variable. Happy practicing!
